# İhale Asistanı

Kamu ihale ilanlarından önemli bilgileri (İKN, idare, konu, son teklif tarihi, ihale usulü) yapay zekâ ile otomatik çıkaran araç.

## Kurulum
1. `python -m venv .venv` ve ortamı etkinleştir
2. `pip install -r requirements.txt`
3. `.env.example` dosyasını `.env` olarak kopyala, kendi anahtarını yaz
